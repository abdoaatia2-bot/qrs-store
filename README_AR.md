# QRS STORE - متجر ألعاب البلايستيشن الليبي

## 🎮 مرحباً بك في QRS STORE

**QRS STORE** هو متجر إلكتروني متكامل متخصص في بيع ألعاب البلايستيشن بأفضل الأسعار وبطرق دفع آمنة وميسرة. المتجر مصمم بأحدث التقنيات وبأسلوب احترافي فائق.

## 🚀 كيفية البدء

### المتطلبات
- Node.js 18+ و npm/pnpm
- قاعدة بيانات (MySQL/PostgreSQL)
- مفاتيح API للخدمات الخارجية

### التثبيت والتشغيل

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd qrs_store_fullstack

# 2. تثبيت المكتبات
pnpm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل الملف بمفاتيح API الخاصة بك

# 4. تشغيل خادم التطوير
pnpm dev

# 5. افتح المتصفح
# http://localhost:5173
```

```typescript

  nameAr: "اسم اللعبة بالعربية",
  price: 250,
  image: "رابط الصورة",

  description: "الوصف الإنجليزي",
```
